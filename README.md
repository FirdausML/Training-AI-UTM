# 🧠 Training and Testing AI for Computer Vision – UTM

This project focuses on training and testing artificial intelligence (AI) models for **Computer Vision (CV)** tasks at **Universiti Teknologi Malaysia (UTM)**. The objective is to develop, train, and evaluate deep learning models to solve real-world vision problems using structured pipelines.

---

## 📌 Project Overview

- **Institution**: Universiti Teknologi Malaysia (UTM)  
- **Focus Area**: Computer Vision (CV)  
- **Goal**: Build robust and accurate deep learning models for image classification, detection, or segmentation tasks.

---

## 🧠 Core Components

### 🔹 Model Training
- Framework: `PyTorch` / `TensorFlow` *(Choose one)*
- Architecture: `ResNet50`, `YOLOv8`, `EfficientNet`, etc.
- Features:
  - Data preprocessing & augmentation
  - Custom loss functions
  - Learning rate schedulers and optimizers

### 🔹 Model Testing & Evaluation
- Evaluation metrics:
  - Accuracy, Precision, Recall
  - F1-Score or mAP (for object detection)
- Visualization:
  - Confusion matrix
  - Output predictions and detection boxes
- Validation strategy:
  - Train-test split or k-fold cross-validation
